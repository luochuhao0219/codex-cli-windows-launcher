# Contributing

Install Node.js, npm, Codex CLI, and Pester on Windows. Run `scripts\Test.ps1` before opening a pull request and `scripts\Build.ps1` before proposing a release. Keep changes in `src`; never edit `dist` as source.

Use focused commits and include tests for parsing, error handling, and cleanup behavior. Do not submit `node_modules`, `dist`, logs, personal absolute paths, proxy addresses, credentials, API keys, cookies, OAuth codes, or tokens. Report bugs with redacted diagnostic output and reproduction steps.
